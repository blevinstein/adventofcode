# 🎄 Advent of Code Solutions 🎅

My personal solutions to [Advent of Code](https://adventofcode.com/) challenges!

Advent of Code is an annual coding challenge with daily programming puzzles throughout December, created by Eric Wastl. Each day unlocks a new two-part puzzle that gets progressively more challenging as Christmas approaches.

Each year has its own directory containing daily puzzle solutions:
- **2016, 2024, 2025** (`y20XX/`): Rust projects with `Cargo.toml`
- **2017, 2018, 2020, 2021**: Python scripts organized by day
- **2022**: TypeScript solutions
- **2023**: JavaScript solutions
